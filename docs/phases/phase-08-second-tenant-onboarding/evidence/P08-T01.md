## Reporte inválido (redactado)

Paquete con `integrations.token = "plain-secret"`. El valor no aparece en el reporte:

```text
{
  "valid": false,
  "schema_version": 1,
  "errors": [
    {
      "path": "integrations.yaml.token",
      "code": "secret_literal",
      "message": "secret values are forbidden"
    },
    {
      "path": "integrations.yaml.token",
      "code": "extra_forbidden",
      "message": "extra fields are forbidden: token"
    }
  ]
}
```

Schema publicado: `src/ia_mcp/onboarding/schemas/tenant-package.schema.json` (`additionalProperties: false`, `schema_version` const 1, referencias URI).

## Decisiones y desviaciones

Ninguna ADR nueva. El loader acepta YAML de bloque y JSON (subconjunto YAML 1.2) sin añadir PyYAML a `pyproject.toml` (archivo fuera de scope). Las referencias se validan por forma URI; no se resuelven contra un secret store.

## Riesgos residuales

El schema JSON viaja junto al módulo y se lee en desarrollo vía `pythonpath`; no se declaró `package-data` en `pyproject.toml` (fuera de archivos permitidos). P08-T02 debe consumir `TenantPackage`/`ValidationReport` sin persistir packages inválidos.
