## Resultado

`RunInvestigationQuery.get(TenantContext, UUID) -> RunInvestigation` reconstruye un run tenant-scoped desde tablas existentes (sin migraciones ni ALTER de owners):

- `RunSummary`: config version, skill, workflow type, MCP server, status, tokens, latencia UTC.
- `ConversationSummary`: ids, status, trigger message id/direction/content_type. Sin body ni `external_user_ref`.
- Retrievals, tools y retries desde `workflow_transition` (payload sanitizado; se descartan chunk/prompt/arguments).
- Workflow, handoff y jobs por joins tenant-scoped. Handoff no expone `patient_reference`, notes ni collected fields.
- Handoff acotado a `workflow_id` (si hay workflow) **y** a la ventana del run; dos runs en la misma conversación no se mezclan.
- Timeline ordenada por timestamp UTC.
- Paginación cursor de tools y audit events; cursor malformado → `InvalidCursor` (`validation_error`).
- Missing y cross-tenant → `RunNotFound` uniforme.
- Consulta autorizada escribe `run_investigation_queried`.
- Run in-flight (`finished_at is None`): ventana abierta `created_at >= started_at` (sin techo).
- Twins de tenant B (mismo id de conversation/message/workflow, `tenant_b_tool`, `out_of_scope`, `tenant_b_job_marker`, `tenant_b_only`) no aparecen en la investigación de A.

No se modificó `redaction.py` ni la propagación/exporter de T01. Se reutilizan `redact`, `sanitize_summary`, `sanitize_payload` y `sanitize_text`.

## Decisiones

- Tools/retrievals se reconstruyen desde `workflow_transition` (no hay tabla `tool_execution`).
- Jobs: tenant + correlation + ventana del run. In-flight: sin cota superior.
- `trace_url` queda `None` (no hay backend de traces).

## Riesgos residuales

`audit_event` **no tiene `run_id`**. El filtro es `tenant_id` + ventana temporal `[started_at, finished_at]` (o abierta si el run sigue in-flight). Eso **no garantiza** aislamiento entre dos runs del mismo tenant que se solapen en el tiempo: eventos de A y de un run concurrente pueden mezclarse. La fixture demuestra que `tenant_b_only` (otro tenant, misma ventana) no aparece; no demuestra separación run-a-run dentro del tenant. P07-T03 debe aplicar RBAC HTTP sin bypassear este query.

Nombres en texto libre (`Juan Perez` en `workflow.error` / `job.last_error`) no son redacted por los helpers actuales.
