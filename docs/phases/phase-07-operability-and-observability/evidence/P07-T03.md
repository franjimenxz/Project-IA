## Resultado

`create_admin_runs_router()` expone investigación de runs **read-only**:

- `GET /v1/admin/runs/{run_id}` JSON
- `GET /admin/runs/{run_id}` HTML server-rendered (sin SPA, sin botones, sin POST)

RBAC reutiliza `Principal` inyectado en `app.state` (mismo patrón que onboarding; no hay login federado). Roles de vista: **`operator` y `auditor`** con assignment de tenant. `tenant_admin` (mismo tenant o ajeno) recibe 403 y no llama al query. El `TenantContext` del query sale de `principal.tenant_id` / `tenant_slug` y de la correlation mint del middleware T01. Headers `X-Tenant-ID` / `X-Tenant-Slug` y `traceparent` inbound no cambian el scope.

Missing y cross-tenant (operator B → run A) responden el mismo 404 T02: `title=not_found`, `detail=Resource not found`. Unauthenticated → 401. `tenant_admin` → 403.

La vista HTML escapa strings controlados por usuario/tenant, muestra timestamps timezone-aware UTC (`+00:00` + etiqueta UTC) y pagina tools/audit con links GET (`tools_cursor` / `events_cursor`). No se renderizan bodies, chunks, prompts, tool payloads ni patient ids completos: se consume `RunInvestigationQuery` y se llama a los sanitize/redact existentes, sin reescribir `redaction.py` ni `run_query.py`.

`create_app` incluye el router con un pinpoint. P08-T03 puede añadir `create_onboarding_router()` en paralelo; no se tocan rutas de onboarding.

El markup crudo no entra al DOM. Pagination: `Next tools` / `Next audit` son `<a href="/admin/runs/{id}?tools_cursor=...">` (GET).

## 404 uniforme

```text
unauthenticated GET JSON/HTML → 401
operator A + missing UUID → 404 title=not_found detail="Resource not found"
operator A + run B         → 404 title=not_found detail="Resource not found"
operator B + run A         → 404 title=not_found detail="Resource not found"
tenant_admin A + run A     → 403
tenant_admin B + run A     → 403
HTML 404 usa el mismo problem+json (no enumeración)
```

## Decisiones

- Auth: `app.state.principal` (`Principal`), sin federated login.
- Vista restringida a `operator`/`auditor` (TDD Phase 7). `tenant_admin` same-tenant es 403. `platform_admin` sin assignment no elige tenant por header.
- 404 HTTP es `application/problem+json` con `title=not_found` para JSON y HTML (uniformidad T02).
- No se registró `register_error_handlers` en `create_app` (seguiría mapeando `RunNotFound` a 400). El router atrapa `RunNotFound`.
