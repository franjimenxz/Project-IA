## Decisiones

- JSON backend-neutral (`alert/v1`, `dashboard/v1`) para un adapter futuro. No se eligió producto de destino.
- Owners son roles (`platform-security`, `workflow-oncall`, `integration-oncall`, `platform-oncall`, `config-oncall`), no destinos de paging.
- Rollback = `ConfigurationService.activate` de una versión publicada anterior; no se borra audit.
- Threshold de cola (`300s`) es operacional interino; `EXT-007` sigue pendiente para SLOs de producción.

## Riesgos residuales

Las métricas nombradas (`isolation_violation_count`, `queue_age_seconds`, etc.) son el contrato del catálogo; el exporter T01 aún no emite todas. Un adapter futuro debe mapearlas sin cambiar estos IDs.

`EXT-007` no fijó umbrales finales. `queue-backlog` medium / 300s puede ajustarse sin reescribir runbooks.

Nombres en texto libre siguen sin redactarse en `redaction.py` (owner P06-T03). Este task rechaza tabletop con prosa libre; no amplia el redactor.
